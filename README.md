# Taller: Introducción a Python 

## Objetivo

Que el estudiante y/o alumno(a) adquiera habilidades técnicas sobre el lenguaje de programación Python, con la finalidad de que pueda utilizarlo con fines estadísticos y/o econométricos.

## Distribución de clases

En el siguiente listado podrás conocer los temas generales que se abordarán en el taller.

### Sesión 1. Introducción a Python para análisis de datos
- Python y Jupyter
- Variables y estructuras básicas
- Operaciones y funciones
- Importación de datos

### Sesión 2. NumPy y Pandas
- Arrays
- Series y DataFrames
- Selección y filtrado
- Creación de variables
- Valores faltantes

### Sesión 3. Manipulación de bases de datos
- Importación de Excel y CSV
- Limpieza de datos
- `groupby`, `merge` y `pivot`
- Transformación de bases

### Sesión 4. Visualización de datos
- Matplotlib
- Gráficas de líneas, histogramas y dispersión
- Visualización de variables económicas
- Personalización de gráficos

### Sesión 5. Python aplicado a econometría
- Matrices y operaciones
- Regresión lineal
- Interpretación de resultados
- Introducción a librerías econométricas
- Preparación de datos para series de tiempo, panel y econometría espacial
